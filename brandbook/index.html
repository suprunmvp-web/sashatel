01 / PhilosophyQuiet technology

Less interface.
More control.

Мы не создаём «ещё один SaaS-дешборд». Мы проектируем инфраструктуру, которую хочется использовать каждый день.

Каждое решение должно делать продукт проще, быстрее и спокойнее. Если элемент не помогает пользователю — он не нужен.

07 / Agent instructionsGPT · UX/UI skill · developer handoff

Understand first.
Then design.

SashaTel Design Standard — обязательный контракт для AI-агента, а не подборка референсов. Использовать ux-ui skill как метод UX-анализа и проверки, а не как генератор случайных модных стилей. Сначала задача человека и существующая функция, потом структура, токены и эстетика.

01 / PRIORITY

Функция → доступность → UX → визуальная система

Запрещено удалять поля, фильтры, звонки и данные ради упрощения картинки. Не придумывать пользователю новые сценарии.

02 / LAYOUT

Пространство вместо плиточного пазла

Использовать логическую группировку и спокойные разделители. Карточки — только при реальной функциональной необходимости.

03 / COLOR

Жёлтый — сигнал, а не обои

95% нейтральных цветов и 5% акцента — правило внимания. Реальные данные диаграмм нельзя подгонять под эти пропорции.

04 / MOTION

Фирменная материя имеет собственные границы

На лендинге — вытянутая дальняя волна. Во время звонка — живое кольцо с локальным свечением и аудиореакцией. В аналитике запрещено.

05 / ICONS

Только конкретные разрешённые Lucide

Одна семантика — одна иконка. Никаких эмодзи, Unicode-подмен, разных толщин или случайных пиктограмм.

06 / ACCEPTANCE

Не утверждать без визуальной проверки

1440, 1280, 1024, 768, 390 px; клавиатура, hover, focus, loading, error, reduced motion, отсутствие обрезанных текстов и горизонтального скролла.

08 / EngineeringSingle source of truth

The details
are the design.

01 / TypeGeist / Geist Mono

Строгая шкала, без случайных начертаний. Tabular numerals для метрик и таблиц.

02 / Grid4 px base

Микроотступы 4–8; связанные элементы 8–16; секции 40–64 px.

03 / SurfaceOne plane

Граница 1 px, радиус 4–8 px. Карточки — только когда группировка функциональна.

04 / Motion120–220 ms

Состояния меняются плавно и предсказуемо; Particle Field учитывает reduced motion.

05 / ChartsSignal on interaction

Светлая тонкая линия и нейтральные сектора. Жёлтый — фокус и выбранный элемент.

Это интерактивная концепция брендбука SashaTel. Численные токены — исходный стандарт для обсуждения и фиксации в engineering spec; не заменяют UX-исследование или проверку реального продукта.
