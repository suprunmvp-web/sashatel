# SashaTel Desktop — v0.1.0

Изолированный прототип desktop-звонилки для macOS и Windows. Он не изменяет существующий веб-кабинет в корне репозитория.

## Запуск

Требуется Node.js 24 LTS и npm.

```bash
cd desktop
npm install
npm start
```

## Что работает

- Окно desktop-приложения, набор и проверка телефонного номера РФ.
- Демо-вызов с состояниями «набор», «соединено», «завершено».
- Локальная история тестовых вызовов и их длительность.
- Безопасные настройки Electron: contextIsolation, sandbox, отключённый Node.js в UI, CSP, отсутствие загрузки внешних страниц.

## Чего пока нет

- Реального соединения SIP/WebRTC и звука в демо-вызовах.
- API, авторизации, многопользовательского режима, записи звонков.
- CDR/CEL, Asterisk, карусели номеров, тарификации и списаний.
- Подписанного установщика и проверенного запуска на macOS/Windows.

## Аудиооснова

Добавлен независимый [Audio Device Service](audio/README.md): реальные устройства,
разрешения macOS, выбор входа/выхода, программное усиление потока, громкость,
измерение входного PCM-сигнала и настоящий тестовый тон. Сервис доступен как
`window.sashatelAudio`; он не подключён к имитации звонков и не добавляет UI.

```bash
npm ci
npm test
npm run test:electron
```

Архитектура, контракт UI/WebRTC и ограничения описаны в документации сервиса;
[результаты проверок и чек-лист MacBook Air](audio/VALIDATION.md) отдельно отличают
синтетические проверки в настоящем Electron от физических проверок на Mac.

Тестовый таймер **не является** доказательством подключения, ответа собеседника или фактических минут. Демо-история не сохраняется между перезапусками.
